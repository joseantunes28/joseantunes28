# Hi, I'm José Antunes

Full-stack software engineer based in Braga, Portugal. I work across the whole stack, from databases, APIs and deployment to web, desktop and mobile interfaces, and I apply AI where it helps: computer vision models and LLM-based tooling. I have an MSc in Mechatronics Engineering and a BSc in Information Systems, so I like projects where software meets hardware.

### Things I've built

**Professionally** (private repositories):

- Real-time, data-heavy web platform in React + TypeScript: live dashboards and charts over WebSockets, user and role management, mobile/tablet layouts, and a migration to a feature-based architecture with work on responsiveness (INP).
- Image annotation and model training tool: bounding-box labelling canvas (draw, zoom, rotate), dataset and model management, and tracking of training runs.
- Shared React + Tailwind component library: a monorepo of versioned packages used by several apps.
- Electron + React desktop app for touch screens, with its own Python/Flask + PostgreSQL back end, an automated backup and versioning system, and Docker Compose deployment.
- REST APIs in Python (Flask) and Node.js, database schemas and migrations, and LLM tooling with Pydantic AI.
- Computer vision: trained and evaluated YOLO and RT-DETR models, converted them to ONNX/TensorRT, and used cleanlab to find annotation problems.
- Device setup automation in Bash: a multi-phase script that turns a fresh Ubuntu or NVIDIA Jetson machine into a running system with one command. It installs Docker and Docker Compose, configures the desktop, auto-login, timezone, a static IP, Tailscale and VNC remote access, activates CPU cores and assigns them to each service, adds log rotation and disk cleanup, applies hardware fixes, then reboots, pulls the images and starts everything as a systemd service.
- Cloud integration: syncing images and data between edge devices and Azure Blob Storage, connecting IoT gateways to AWS IoT Core over MQTT, and hosting front ends on AWS Amplify.
- Edge and DevOps: Docker images for amd64 and NVIDIA Jetson, and GitHub Actions pipelines that build and publish them.

**Personal and freelance projects:**

- **NavMap** (private): an offline-first navigation app for off-road and on-road trips (enduro, 4x4, MTB, hiking). Offline vector maps (PMTiles + MapLibre), on-device route calculation with BRouter and custom driving modes, GPS recording in the background, GPX import/export, a rally-style roadbook with PDF export, and Android Auto support. *React Native, Expo, TypeScript, Kotlin native modules.*
- **Vehicle Deal Finder**: searches car and motorcycle listings live on Portuguese marketplaces, stores them in SQLite and scores each one against similar listings to find good deals. *Python, Playwright, httpx, Streamlit.*
- **Online store** (freelance, in progress): an e-commerce site for a client with product variants, promotions, personalised products and Stripe payments (card, Multibanco, MB WAY). *Medusa v2, Next.js 15, PostgreSQL.*
